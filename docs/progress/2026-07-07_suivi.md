# Suivi du 7 juillet 2026

## Réalisations

Le dossier de données est complet. Chaque source est confirmée dans le README avec son format, sa projection et son lien d'accès.

La description de l'utilisation du sol de la CMM est corrigée. Ce sont des shapefiles vectoriels et non un raster.

Le réseau de transport collectif exo est intégré. Les arrêts d'autobus viennent du GTFS de la CITVR. Les gares et les lignes de train complètent le réseau. L'accès aux services ne se mesure donc plus seulement à pied.

L'environnement conda est en place avec environment.yml et requirements.txt.

Les tests unitaires pytest et l'intégration continue GitHub Actions sont ajoutés avec un badge de statut dans le README.

La fonction de reprojection est écrite et testée. Le README et le schéma du pipeline sont à jour.

## Décisions prises

L'analyse retient le réseau fixe seulement, sans horaires ni temps réel. Les emplacements du service exo à la demande ne sont pas diffusés.

Le train joue un rôle complémentaire. Les deux gares agissent comme points d'accès. Les arrêts d'autobus restent la couche dominante.

## Points ouverts

La présence de trottoirs sur les ponts du Richelieu reste à valider avec l'imagerie aérienne.

Les CRS des sources sont variés. Une reprojection unique vers EPSG 2950 règle ce point et un test la couvre.
