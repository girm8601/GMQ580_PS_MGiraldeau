# Suivi du 7 juillet 2026

## Réalisations

- Dossier de données complet. Chaque source est confirmée dans le README avec son format, sa projection et son lien d'accès.
- Description de l'utilisation du sol de la CMM corrigée. Ce sont des shapefiles vectoriels et non un raster.
- Réseau de transport collectif exo intégré. Les arrêts d'autobus viennent du GTFS de la CITVR, les gares et les lignes de train complètent le réseau.
- Environnement conda en place avec environment.yml et requirements.txt.
- Tests unitaires pytest et intégration continue GitHub Actions ajoutés, avec un badge de statut dans le README.
- Fonction de reprojection écrite et testée. Le README et le schéma du pipeline sont à jour.

## Décisions prises

- L'analyse retient le réseau fixe seulement, sans horaires ni temps réel. Les emplacements du service exo à la demande ne sont pas diffusés.
- Le train joue un rôle complémentaire. Les deux gares agissent comme points d'accès, les arrêts d'autobus restent la couche dominante.
- Les CRS des sources sont variés. Une reprojection unique vers EPSG 2950 règle ce point et un test la couvre.

## Points ouverts

- La présence de trottoirs sur les ponts du Richelieu reste à valider avec l'imagerie aérienne.
